# 문항 레코드 스키마

JSONL 형식의 문항 레코드 구조를 정의합니다. 각 줄은 다음과 같은 스키마를 따릅니다.

## 레코드 구조

```json
{
  "id": "2005MC30",
  "exam": {
    "schoolYear": 22,
    "month": "00",
    "number": 30,
    "points": 4,
    "label": "2022학년도 예비시행 기하 30번"
  },
  "subject": "기하",
  "topic": "정사영",
  "mode": "3d",
  "statement": "<KaTeX-ready LaTeX>",
  "answer": "<string>",
  "scale": 24,
  "camera": { "rotX": 0.42, "rotY": -0.28, "zoom": 1.5 },
  "objects": [ ... ],
  "steps": [ { "text": "...", "show": ["tag"...], "focus": ["tag"...]?, "camera": {...}? }, ... ],
  "theorems": [ { "key": "orthogonal-projection-proof", "label": "정사영 넓이 S'=S cos θ" } ]
}
```

## 필드 설명

### 기본 필드

- **id** (필수, 문자열): 문항의 고유 식별자 (예: "2005MC30")
- **exam** (필수): 시험 정보
  - **schoolYear** (필수, 정수): 학년도 (예: 22 = 2022학년도)
  - **month** (필수, 문자열): 시험 월 ("00"|"06"|"09"|"11")
  - **number** (필수, 정수): 문항 번호
  - **points** (필수, 정수): 배점 (현재 4점 고정)
  - **label** (필수, 문자열): 문항 라벨 (예: "2022학년도 예비시행 기하 30번")
- **subject** (필수, 문자열): 과목 (현재 "기하"만 지원)
- **topic** (필수, 문자열): 단원 (하나를 선택)
  - "정사영", "이면각", "삼수선", "구", "단면", "공간좌표", "벡터연산", "내적", "자취"
- **mode** (필수, 문자열): 렌더링 모드 ("3d"|"2d")
- **statement** (필수, 문자열): 문항 진술 (KaTeX 형식의 LaTeX)
- **statement_en** (선택, 문자열): statement의 영문 번역. 수식(`$...$`, `$$...$$`)은 원문과 동일하게 유지하고 한국어 서술만 번역한다. 없으면 영문 모드에서도 statement로 폴백한다.
- **answer** (필수, 문자열): 정답
- **scale** (필수, 양수): 스케일 배수

### 선택 필드

- **camera** (선택): 카메라 초기 설정
  - **rotX** (선택, 수): X축 회전각
  - **rotY** (선택, 수): Y축 회전각
  - **zoom** (선택, 수): 줌 배수
- **objects** (필수): 객체 배열 (최소 1개)
- **steps** (필수): 풀이 단계 배열 (최소 2개)
- **theorems** (선택): 정리 및 공식 배열

## 객체 타입

모든 객체는 다음 공통 필드를 가집니다:

- **id** (필수, 문자열): 객체의 고유 식별자
- **type** (필수, 문자열): 객체 타입
- **tags** (필수, 배열): 문자열 태그 배열 (비어있지 않아야 함)
- **color** (선택, 문자열): 색상 ("A"|"B"|"C"|"D"|"E"|"muted"|"text", 기본값 "text")

### 타입별 필드

#### point (점)
- **at** (필수): `[x, y, z]` 좌표
- **label** (선택): 점의 라벨 텍스트

#### segment (선분)
- **from** (필수): `[x, y, z]` 시작점
- **to** (필수): `[x, y, z]` 끝점
- **dash** (선택): `[패턴, 간격]` 대시 패턴
- **width** (선택): 선의 너비

#### plane (평면)
- **corners** (필수): `[[x,y,z], ...]` 좌표 배열 (최소 3개)
- **alpha** (선택): 평면의 투명도
- **label** (선택): 평면의 라벨
- **label_en** (선택): label의 영문 번역 (캔버스에 직접 그려지는 라벨이므로 KaTeX가 아닌 plainMath 변환을 거친다). 없으면 영문 모드에서도 label로 폴백한다.

#### sphere (구)
- **center** (필수): `[x, y, z]` 구의 중심
- **r** (필수): 양수, 구의 반지름

#### circle (원)
- **center** (필수): `[x, y, z]` 원의 중심
- **normal** (필수): `[x, y, z]` 원의 법선 벡터
- **r** (필수): 양수, 원의 반지름
- **dash** (선택): `[패턴, 간격]` 대시 패턴

#### projection (정사영)
- **of** (필수): 정사영할 circle 객체의 id
- **toZ** (필수): 정사영을 그릴 z 평면 높이
- **dash** (선택): `[패턴, 간격]` 대시 패턴

#### rightangle (직각)
- **vertex** (필수): `[x, y, z]` 직각의 꼭짓점
- **a** (필수): `[x, y, z]` 첫 번째 변의 방향
- **b** (필수): `[x, y, z]` 두 번째 변의 방향

#### vector (벡터)
- **from** (필수): `[x, y, z]` 벡터의 시작점
- **to** (필수): `[x, y, z]` 벡터의 끝점
- **width** (선택): 선의 너비 (기본값 2.5)
- **dash** (선택): `[패턴, 간격]` 대시 패턴
- **label** (선택): 벡터의 라벨 텍스트
- **label_en** (선택): label의 영문 번역. plane의 label_en과 동일한 규칙을 따른다.

#### arc (호)
- **center** (필수): `[x, y, z]` 호의 중심
- **a** (필수): `[x, y, z]` 호의 시작점 방향
- **b** (필수): `[x, y, z]` 호의 끝점 방향
- **r** (선택): 화면 픽셀 단위의 호의 반지름 (기본값 22)
- **label** (선택): 호의 라벨 텍스트
- **label_en** (선택): label의 영문 번역. plane의 label_en과 동일한 규칙을 따른다.

#### arc3d (3D 매끄러운 호)
- **center** (필수): `[x, y, z]` 호의 중심
- **r** (필수): 양수, 호의 반지름 (from/to/via가 실제로 이 반지름 위에 있어야 함)
- **from** (필수): `[x, y, z]` 호의 시작점 (반지름 위)
- **to** (필수): `[x, y, z]` 호의 끝점 (반지름 위)
- **via** (필수): `[x, y, z]` 호가 지나는 경유점 (반지름 위). from→to를 via를 지나는 방향으로 잇는 매끄러운 3D 호를 48분할로 샘플링해 그린다.
- **width** (선택): 선의 너비 (기본값 2)
- **dash** (선택): `[패턴, 간격]` 대시 패턴

#### label (라벨)
- **at** (필수): `[x, y, z]` 라벨 위치
- **text** (필수): 라벨 텍스트
- **text_en** (선택): text의 영문 번역. plane의 label_en과 동일한 규칙을 따른다.
- **size** (선택): 텍스트 크기

#### ellipse (타원) — 2d 전용
- **center** (필수): `[x, y, z]` 타원의 중심 (z=0)
- **rx** (필수): 양수, x축 방향 반지름
- **ry** (필수): 양수, y축 방향 반지름
- **dash** (선택): `[패턴, 간격]` 대시 패턴
- **width** (선택): 선의 너비 (기본값 2)

지역좌표(center 기준) `(rx·cos t, ry·sin t, 0)`, `t ∈ [0, 2π]`를 64분할(65정점)로 샘플링해 닫힌 곡선으로 그린다.

#### parabola (포물선) — 2d 전용
- **form** (필수): `"y2=4px"` | `"x2=4py"`
- **p** (필수): 0이 아닌 수 (초점 거리 계수)
- **vertex** (필수): `[x, y, z]` 포물선의 꼭짓점 (z=0)
- **span** (필수): 양수, 매개변수 t의 범위 `[-span, span]`
- **dash** (선택): `[패턴, 간격]` 대시 패턴
- **width** (선택): 선의 너비 (기본값 2)

지역좌표(vertex 기준):
- `form: "y2=4px"` (y²=4px 표준형): `(t²/(4p), t, 0)`
- `form: "x2=4py"` (x²=4py 표준형): `(t, t²/(4p), 0)`

`t ∈ [-span, span]`을 48분할(49정점)로 샘플링해 열린 곡선으로 그린다. 닫지 않는다.

#### hyperbola (쌍곡선) — 2d 전용
- **form** (필수): `"x2-y2"` | `"y2-x2"`
- **a** (필수): 양수
- **b** (필수): 양수
- **center** (필수): `[x, y, z]` 쌍곡선의 중심 (z=0)
- **span** (필수): 양수, 매개변수 t의 범위 `[-span, span]`
- **branch** (필수): `"both"` | `"pos"` | `"neg"` — 그릴 가지
- **dash** (선택): `[패턴, 간격]` 대시 패턴
- **width** (선택): 선의 너비 (기본값 2)

지역좌표(center 기준):
- `form: "x2-y2"` (x²/a²−y²/b²=1 표준형): `(±a·cosh t, b·sinh t, 0)` — 부호는 가지(branch) 선택
- `form: "y2-x2"` (y²/a²−x²/b²=1 표준형, 축 교환): `(b·sinh t, ±a·cosh t, 0)`

`t ∈ [-span, span]`을 가지당 40분할(41정점)로 샘플링한다. `branch: "both"`는 양(pos)·음(neg) 두 가지를 **별개의 폴리라인**으로 각각 그리며 서로 연결하지 않는다. `branch: "pos"`/`"neg"`는 해당 가지 하나만 그린다.

준선·점근선은 기존 `segment`(대시) 타입으로, 초점·꼭짓점은 기존 `point` 타입으로 표현한다.

## 좌표계 규약

좌표는 문항의 수학 좌표계(z-up) 그대로 적는다. 렌더러가 화면 좌표(y-up)로 `[x,y,z] → (x*scale, z*scale, y*scale)` 매핑한다. `scale`은 문항 좌표를 엔진 월드(±110 근방)로 키우는 배율이다. steps의 `show`는 해당 단계에서 보이는 태그 집합, `focus`는 그중 강조(불투명·굵게)할 태그이며 show에 포함된 나머지는 흐리게(0.35) 그린다.

## 풀이 단계 (steps)

각 단계는 다음 구조를 가집니다:

```json
{
  "text": "단계 설명",
  "show": ["태그1", "태그2"],
  "focus": ["태그1"],
  "camera": { "rotX": 0.42, "rotY": -0.28, "zoom": 1.5 }
}
```

- **text** (필수): 단계 설명 텍스트
- **text_en** (선택): text의 영문 번역. statement_en과 동일한 규칙(수식 보존, 서술만 번역)을 따른다. 없으면 영문 모드에서도 text로 폴백한다.
- **show** (필수): 이 단계에서 보여줄 객체 태그 배열
- **focus** (선택): show에 포함된 태그 중 강조할 태그 배열
- **camera** (선택): 이 단계의 카메라 설정 (전체 레코드 camera와 동일한 구조)

## 정리 및 공식 (theorems)

```json
{
  "key": "orthogonal-projection-proof",
  "label": "정사영 넓이 S'=S cos θ"
}
```

- **key** (필수): 정리의 고유 식별자
- **label** (필수): 정리의 표시 라벨

## 2D 모드 규칙

모드가 `"2d"`인 경우:

- **카메라 고정**: `camera` 필드는 필수이며, 다음 값을 정확히 가져야 합니다:
  - `rotX: -1.5708` (±0.001 허용)
  - `rotY: 0`
- **Z 좌표 고정**: 모든 객체의 3D 좌표(점, 벡터, 호, 직각 등)는 `z = 0`을 만족해야 합니다.
  - 예외: `circle` 타입의 `normal` 필드는 `[0, 0, 1]`이 허용됩니다. (2D 평면 위 원의 법선)
- **이차곡선 2d 전용**: `ellipse`/`parabola`/`hyperbola` 타입은 2d 전용 객체이며, `mode: "3d"` 레코드에서 사용하면 검증 에러가 발생합니다.

예시:
```json
{
  "mode": "2d",
  "camera": { "rotX": -1.5708, "rotY": 0, "zoom": 1 },
  "objects": [
    { "id": "A", "type": "point", "at": [1, 2, 0], "tags": ["given"] },
    { "id": "v", "type": "vector", "from": [0, 0, 0], "to": [1, 0, 0], "tags": ["s1"] },
    { "id": "c", "type": "circle", "center": [0, 0, 0], "normal": [0, 0, 1], "r": 2, "tags": ["s1"] }
  ]
}
```

## 검증 규칙

- 레코드는 모든 필수 필드를 포함해야 합니다.
- `objects` 배열은 최소 1개의 객체를 포함해야 합니다.
- `steps` 배열은 최소 2개의 단계를 포함해야 합니다.
- 모든 객체 id는 중복되지 않아야 합니다.
- `steps`의 `show`와 `focus`에서 참조하는 모든 태그는 `objects`의 태그에 포함되어야 합니다.
- `projection` 객체의 `of` 필드는 존재하는 circle 객체의 id를 참조해야 합니다.
- `ellipse`/`parabola`/`hyperbola` 객체는 `mode: "3d"` 레코드에서 사용할 수 없습니다 (2d 전용).
